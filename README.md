**A full-featured social media mobile client inspired by Instagram, engineered with Flutter, BLoC state management, and Firebase.**

</div>

---

## ✨ Key Features

- 🖼️ **Dynamic Feed & Stories:** Smooth infinite-scroll photo/video feed, likes, comments, and story highlights.
- 📤 **Media Upload & Compression:** Camera & gallery picker with client-side image cropping and Firebase Cloud Storage uploads.
- 💬 **Real-Time Activity & Notifications:** Instant updates for likes, follows, and comments via Cloud Firestore streams and FCM.
- 👤 **User Profiles & Follow System:** Customizable profiles, follower/following graphs, and grid/list post views.
